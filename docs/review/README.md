# 判级争议样本复核（已合并人工判读）

样本：42 张（模型判级比标注高 2 级及以上），逐张目视复核。

## 结论

| 判定 | 数量 | 占比 |
| --- | ---: | ---: |
| 模型误检 | 39 | 93% |
| 标注漏标 | 3 | 7% |
| 存疑 | 0 | 0% |

**93% 的争议样本确认是模型误检**，只有 3 张是标注漏标。
误杀率不是被标签噪声吹大的——模型确实在过度检测。

## 失败模式

- 34 张（81%）的预测框总面积超过图像 40%，几乎盖住整个零件；
- 这些大框都出现在「正确检出真实缺陷」之外，属于多画的一层；
- 判级按覆盖面积算，面积被撑到 100% 以上，等级直接顶到 IV。

说明**面积阈值不能代替人工判断**——这正是需要人工真值等级的原因。

## 对判级实验的影响

1. 误杀是真实存在的，不能归因于标注噪声；
2. 仍有 7% 的样本是标注漏标——这类噪声会同时抬高「参考等级」和「模型等级」，两级都失真；
3. 因此判级结论应表述为「在此标注下的一致性」，而不是「判级准确率」。
