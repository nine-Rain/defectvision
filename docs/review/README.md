# 判级争议样本复核（第一轮）

## 样本构成

- 共 42 张，筛选条件是"模型判级比标注高 2 级及以上"
- 其中 **34 张（81%）模型输出的框总面积超过图像 40%**
- 涉及模型：RT-DETR-l、自研 CNN、YOLOv8s、YOLO11n

## 目视复核结论（AI 侧）

逐张看完 11 张拼图后，失败模式高度一致：

1. **这些图大多确实存在真实缺陷**（绿色标注框可见，模型也检出了）；
2. **模型同时还输出了 1~3 个几乎盖住整个零件的框**，把面积撑到 100% 以上；
3. 判级只看覆盖面积 → 面积越界 → 直接判 III/IV。

也就是说，误杀的主因不是"无中生有"，而是**在正确检出之外多给了整体框**。

## 一个反直觉的验证

按这个结论加了"过滤超过 40% 面积的整体框"的规则，结果：

| 模型 | 一致率 | IV 召回 | 误杀率 |
| --- | ---: | ---: | ---: |
| RT-DETR（过滤前） | 81.3% | 99.0% | 28.1% |
| RT-DETR（过滤后） | 65.3% | **64.3%** | 18.8% |
| YOLOv8s（过滤前） | 83.3% | 93.9% | 6.2% |
| YOLOv8s（过滤后） | 60.0% | **57.1%** | 3.1% |

**误杀降了，但 IV 召回崩了**：MSDD 里很多真实严重缺陷本身就是大面积，
一刀切会把真缺陷一起删掉。

## 结论

**"整体框"是误杀的直接原因，但不能靠尺寸阈值解决**——因为参考标准（标注框）
和模型输出用的是同一套"面积"语义，任何收紧规则都会同时削弱真缺陷。

真正要做的，是让标准脱离"框面积"：**人工标注 50~100 张图片的真实等级**，
用人的判断做真值，再回头评估模型。这一步不做，判级实验永远是在自证。
