# 标注规范

> 标注质量决定项目上限。模型再强，也救不回"同一个缺陷两个人标得不一样"。
> 这份文档要在标第一张图之前定下来，之后每次有争议都回来补一条。

## 1. 类别定义

| id | 名称 | 定义（什么算） | 不算什么 |
| --- | --- | --- | --- |
| 0 | scratch | 长度 > 5mm 的线状划伤，可见明显色差 | 反光、纹理纹路、灰尘 |
| 1 | dent | 面积 > 3mm² 的凹陷，边缘有阴影过渡 | 平面上的印刷图案 |
| 2 | stain | 与底色色差明显、边界模糊的污渍 | 水渍反光、镜头脏点 |

> 上表是**模板**。换成你自己的类别，每个类别都要写"算"和"不算"两列——
> 只写"算"的那一半，标注员遇到边界样本一定会问你。

## 2. 框的规则

1. **紧贴目标外轮廓**，不预留背景，也不切掉目标。
2. **遮挡**：目标被遮挡超过 50% 不标；不足 50% 按可见部分标框（并在 `attributes` 里记 `occluded`）。
3. **截断**：目标在图像边缘被截断，仍然标，框贴到图像边界。
4. **最小尺寸**：短边小于 8px 的不标——这个尺度模型学不到，标了只会引入噪声。
5. **一个目标一个框**，不要用一个大框套住多个缺陷。
6. **负样本**（无缺陷）也要收，标签文件留空。真实产线里大量是良品，全给正样本会让模型到处误检。

## 3. 工具链

推荐 **Label Studio**（本地起服务）或 **Roboflow**（在线，能直接导出 YOLO 格式）。

导出格式必须是：

```
labels/
└── train/
    ├── img_0001.txt
    └── ...
```

每行：`class_id cx cy w h`，全部归一化到 0~1。坐标系原点在**左上角**。

## 4. 质检流程（别省）

1. **自标 50 张 → 停**。用这 50 张检查类别定义有没有歧义，改文档。
2. **两人各标 100 张 → 算一致性**。按框的 IoU > 0.5 匹配，类别一致率低于 90% 就回去改定义。
3. **抽查 10%**。训练前跑一次 `python -m src.prepare stats`，把报错的标签全部修掉。
4. **训练后看 badcase**。把误检/漏检的图挑出来，判断是"模型不行"还是"标注错了"——
   经验上前期 70% 是标注错了。

## 5. 常见坑

- 用画图软件手写 txt：坐标系搞反（左下角原点），训练 loss 不降。
- 类别 id 从 1 开始：`names` 必须是 0..N-1 连续整数。
- 标完不检查：`cx=1.2` 这种越界坐标会被裁掉，框全跑到角落。
- 同一个物体在不同图里标了不同类别：先统一命名，再谈模型。
- 拿视频抽帧当独立样本：相邻帧几乎一样，验证集会"泄漏"，指标虚高。
  抽帧要间隔足够大，或者按视频划分 train/val。
